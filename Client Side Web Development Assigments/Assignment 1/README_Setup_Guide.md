# Lab Session 1: Lab Setup & Environment Configuration

## 1. Required Software
- **Visual Studio Code (VS Code):** Primary code editor.
- **Google Chrome / Edge / Firefox:** Modern web browser for testing.

## 2. Recommended VS Code Extensions
1. **Live Server** (Ritwick Dey) – Launches a local development server with live reload.
2. **Prettier - Code formatter** – Automatically formats HTML/CSS/JS code.
3. **Auto Rename Tag** – Automatically renames paired HTML tags.
4. **Auto Close Tag** – Automatically adds closing HTML tags.
5. **HTML CSS Support** – Intellisense for CSS classes and IDs.
6. **HTMLHint** – Static code analysis for HTML errors.

## 3. How to Run in VS Code
1. Open the `Client Side Web Development Assigments` folder in VS Code.
2. Open any `.html` file.
3. Right-click inside the editor and select **Open with Live Server** (or click **Go Live** at the bottom right).
